Partnerlinks: zo verdienen we geld

ToolMatch is gratis en je hebt geen account nodig. Om de site te kunnen maken, kunnen we partnerlinks gebruiken. Hier lees je wat dat betekent.

Wat is een partnerlink?

Een partnerlink is een link naar een aanbieder waarbij ToolMatch een vergoeding kan krijgen als je via die link een abonnement neemt. Voor jou verandert de prijs daardoor niet.

Zo herken je ze

  • Naast een partnerlink staat altijd het woord partnerlink.
  • Zo'n link heeft in de code rel="sponsored nofollow", zoals zoekmachines vragen.
  • Alle andere links naar aanbieders zijn gewone links naar hun eigen site.

Geen invloed op de volgorde

De keuzehulp en onze vergelijkingen rekenen alleen met wat bij jouw situatie past: je doel, budget, team, privacy-eisen en techniek. De partnerlinks staan in een apart bestand dat de berekening niet gebruikt. Een aanbieder kan geen betere plek kopen.

Stand van zaken

Op dit moment staan er nog geen partnerlinks op ToolMatch. Alle links naar aanbieders zijn gewone links.
